# 🏨 Hostel Management System in C

A simple console-based **Hostel Management System** developed in **C language**. This project allows users to manage hostel room allocations, track student details, and monitor room availability efficiently.

## 📚 About This Project

This system is designed using basic C programming concepts such as:

* Structures
* Arrays
* Functions
* Conditional statements
* Loops

It simulates a real-world hostel environment where rooms can be allocated, viewed, and deallocated.


## 🚀 Features

* 📊 Show total, occupied, and vacant rooms
* 🏠 Allocate room to a student
* 🔍 View details of a specific room
* 📋 View all rooms status
* ❌ Deallocate (free) a room
* 🧾 Store student information (ID, Name, Age)


## 🧠 Concepts Used

* Structures (`struct Student`, `struct Room`)
* Arrays (to manage multiple rooms)
* Functions (modular programming)
* Input/Output handling
* Menu-driven program

---

## 🧪 Functionality Overview

### 🔹 Room Initialization

* All rooms are initialized as vacant at the start.

### 🔹 Room Allocation

* User enters room number and student details.
* Room is marked as occupied.

### 🔹 View Room

* Displays student details if room is occupied.

### 🔹 View All Rooms

* Displays status of all rooms (Occupied/Vacant).

### 🔹 Deallocation

* Removes student from room and marks it vacant.
